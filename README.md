# Portfolio

A personal portfolio site for John Sanchez, an aspiring software developer at [i.c.stars](https://icstars.org). It's a single-page site with an About section, a Projects section (including a write-up of the Medline solution — a tool for tracking and identifying reported incidents), and a Contact section with email and GitHub links.

## Technologies

- HTML5 (semantic sections, single `index.html` page)
- CSS3 (custom properties for theming, flexbox layout, no framework or build step)

No JavaScript, frameworks, or build tools are used — it's a static site that runs directly in the browser.
